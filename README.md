# IP Telephony (VoIP) Network Project

## Overview
Designed and implemented a VoIP-based enterprise network using VLAN segmentation, OSPF routing, and DHCP services. The project demonstrates integration of voice and data networks with proper segmentation and routing.

## Key Features
- VLAN segmentation for voice and data traffic
- Inter-VLAN routing using multilayer switching
- Dynamic routing using OSPF
- DHCP configuration for IP address allocation
- VoIP implementation using Cisco Voice Gateway
- Dial-peering configuration for call routing

## Technologies Used
- VLAN
- OSPF
- DHCP
- VoIP
- Routing & Switching

## Tools
- Cisco Packet Tracer

## Project Files
- `IP TELEPHONY.pkt` – Packet Tracer project file  
- `networking.PNG` – Network topology diagram  
- `output.mp4` – Project demonstration video  

## Outcome
This project demonstrates hands-on experience in VoIP deployment, network segmentation, and routing, aligned with CCNA-level networking concepts.
